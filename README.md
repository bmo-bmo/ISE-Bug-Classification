## ISE Bug Report Classification Coursework

## Overview
This project classifies GitHub bug reports as performance-related 
or not across five deep learning projects: caffe, incubator-mxnet, keras, pytorch and tensorflow.

## Models used for this project
- Baseline: Gaussian Naive Bayes + TF-IDF
- Proposed 1: LinearSVM + Enhanced TF-IDF
- Proposed 2: Random Forest + Enhanced TF-IDF
